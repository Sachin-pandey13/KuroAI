# KuroAI 2.0 Architectural Constitution (Version 1.0 Frozen)

## Preamble
KuroAI 2.0 is an **Autonomous AI Manga Studio** powered by a team of stateless, specialized AI agents collaborating with the user (Human Creative Director) via a shared, event-driven Project State Engine (Blackboard Architecture).

---

## Section I: The Six Laws of KuroAI

### First Law (Incremental Preservation)
The system must never force the user to restart creative work because of a later modification. If a user changes a single detail (e.g., hairstyle, camera angle, dialogue line), the system shall evaluate the Directed Acyclic Graph (DAG) of node dependencies, selectively invalidate only affected downstream artifacts, and preserve everything else.

### Second Law (Transparency & Reproducibility)
Every AI decision must be transparent, explainable, and 100% reproducible. Every artifact generated by an agent must include a structured `DecisionTrace` containing confidence score, reasoning rationale, identified risks, evaluated alternatives, and exact execution provenance (prompts, seeds, model identifiers, LoRAs, ControlNets, samplers, hyper-parameters).

### Third Law (Editability & Reversibility)
Every creative artifact must be editable and reversible. Edits shall be non-destructive and tracked at the node level within the `VersionGraph`. Users can view, roll back, branch, or manually override any artifact at any point in history.

### Fourth Law (State Single Source of Truth)
The Project State Engine (Blackboard) is the sole owner and single source of truth for all project data. Agents are strictly **stateless transformers** that accept context inputs and output state deltas, events, and decision traces. Agents shall never persist or own project state locally.

### Fifth Law (Single Responsibility & Decoupling)
Every agent must specialize in a single domain of expertise and collaborate exclusively via shared state events published to the Project State Engine. Direct inter-agent invocation or coupling is strictly prohibited.

### Sixth Law (Human Final Authority)
Human creativity has absolute, final authority over AI autonomy. The user directs the vision, sets goal constraints, overrides AI proposals, and selects working autonomy levels (Guided Mode, Smart Mode, Autonomous Studio Mode).

## Section III: Engineering Standards
1. **Contract-First Architecture:** No engine or agent code shall be written without first defining and freezing its contract schema in `backend/contracts/`.
2. **Type Safety & Pydantic v2:** All contracts use strict Python type annotations and Pydantic v2 models.
3. **Usable Milestones:** Development proceeds in isolated, fully verified milestones (Contracts & Skeleton $\rightarrow$ State Engine $\rightarrow$ Dependency Graph $\rightarrow$ Event Bus $\rightarrow$ Scheduler $\rightarrow$ Capabilities $\rightarrow$ Agents $\rightarrow$ Integration).
4. **Single Responsibility:** Every module has a single, well-defined contract. No feature bleed across phases.
