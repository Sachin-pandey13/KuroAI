# KuroAI

KuroAI is a multi-model generative AI system designed to create coherent multi-page manga stories by orchestrating large language models, fine-tuned diffusion-based image generation models, and structured pipeline logic.

## Key Features
- LLM-based story planning and scene decomposition
- Fine-tuned diffusion model for anime-style image generation
- Character consistency across panels
- Modular, config-driven AI pipeline
- CI/CD-enabled inference deployment
